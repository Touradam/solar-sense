**Making Solar Energy Safer, Smarter & More Sustainable.**

Solar Sense delivers intelligent rapid shutdown compliance and real-time fault detection for photovoltaic systems.

## ✨ About Solar Sense

Solar Sense is an all-in-one device that combines:

- **NEC 2017 Rapid Shutdown Compliance** - Meets safety standards for rooftop solar installations
- **Real-time Fault Detection** - AI-powered monitoring detects panel degradation and electrical issues
- **Module-Level Monitoring** - Track performance of individual solar panels
- **Predictive Maintenance** - Identify problems before they cause system failures
- **Easy Installation** - Simple plug-and-play integration with existing solar systems

## 🚀 Our Mission

At Solar Sense, we believe that the future of solar energy lies in systems that are intelligent, self-aware, and safe by design. We're building affordable solar monitoring technology for the commercial PV sector, preventing millions of dollars in premature decommissioning while extending the productive life of solar installations.

## 🌟 The Journey

Solar Sense's journey began in Summer 2023 during the NSF Innovators Program at Aalborg University in Denmark, where we identified a critical challenge in understanding solar panel degradation. Since then, we've:

- Built 4 generations of Solar Sense prototypes
- Won multiple awards including InventOR 2024 Visionary Award
- Participated in leading accelerators: TiE Oregon, Janus Innovation Hub, Plug and Play Tech Center
- Developed in-house manufacturing capabilities
- Established partnerships with solar industry leaders

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Touradam/solar-sense.git
cd solar-sense

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```
